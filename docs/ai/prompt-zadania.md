# Prompt startowy

Poniżej treść zadania rekrutacyjnego, którą przekazałem agentowi AI (Claude) jako pierwszy prompt.
Na jej podstawie agent zaproponował pomysł (EcoRoute), architekturę i wygenerował pierwszą wersję kodu.

---

Stwórz prostą, pełnostosową aplikację webową (Full-Stack MVP), której tematyka nawiązuje do transportu.
Może to być na przykład: planer podróży, agregator rozkładów jazdy, aplikacja do organizowania wspólnych
przejazdów, narzędzie do porównywania różnych środków transportu lub inny pomysł w tym obszarze.

Liczymy na Twoją kreatywność. Z chęcią zobaczymy aplikacje wykorzystujące AI. […]

Wymagania technologiczne:
* Back-end: dowolny język i framework; API obsługujące podstawowe operacje (CRUD).
* Front-end: dowolny framework / czysty JS/TS; płynna komunikacja z API.
* Baza danych: In-Memory lub SQLite.
* Swoboda narzędzi (w tym narzędzia AI).
* UX/UI: aplikacja intuicyjna i przyjemna w użyciu.

Na co zwracamy uwagę: architektura i organizacja projektu, jakość i czytelność kodu, projekt API
(REST, CORS), dbałość o UX/UI, „creative twist”.
